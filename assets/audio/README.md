# Audio Assets

This folder should contain ambient audio files for the **Peaceful Corner** feature.

## Required Files

| Filename      | Description              | Format |
|---------------|--------------------------|--------|
| `rain.mp3`    | Gentle rain sounds       | MP3    |
| `forest.mp3`  | Soft forest ambience     | MP3    |
| `water.mp3`   | Gentle flowing water     | MP3    |

## Where to Find Free Audio

You can find royalty-free ambient sounds from:

- [Pixabay](https://pixabay.com/sound-effects/) — Free for personal and commercial use
- [Freesound](https://freesound.org/) — Creative Commons licensed sounds
- [Mixkit](https://mixkit.co/free-sound-effects/) — Free sound effects

## Tips

- Keep files small (under 5MB each) for faster loading.
- Loop-friendly audio works best (seamless loop).
- The website works perfectly without audio files — users will see a friendly message if files are missing.
