# Assets

This folder contains all local assets for Manika's Little World.

## Structure

```
assets/
├── audio/          — Ambient sound files (rain.mp3, forest.mp3, water.mp3)
│   └── README.md   — Instructions for adding audio files
└── README.md       — This file
```

## Notes

- Audio files are **not included** by default. See `audio/README.md` for instructions.
- The website is fully functional without audio files — the Peaceful Corner shows a helpful message and works visually.
- All visual effects are created with CSS and JavaScript (no image assets required).
